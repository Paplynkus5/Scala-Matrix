class Matrix(val rows: Int, val columns: Int, collection: Seq[Double])

A class of (mathematical) matrix objects of dimensions m*n containing Double values.

A class of (mathematical) matrix objects of dimensions m*n containing Double values.

Value parameters

collection

A collection of Double-type values to fill the matrix with, supplied in a single object. If there are fewer objects than slots in the matrix (that is, rows * columns), the missing values will default to 0.0. Conversely, if there are too many elements, only the first (rows * columns) will be taken into account.

columns

The number of columns (n) that the newly created matrix will have. Must be an integer greater than 0.

rows

The number of rows (m) that the newly created matrix will have. Must be an integer greater than 0.
