class Matrix(val rows: Int, val columns: Int, collection: Seq[Double])

A class of (mathematical) matrix objects of dimensions m*n containing Double values.

Value parameters

collection

A collection of Double-type values to fill the matrix with, supplied in a single object. If there are fewer objects than slots in the matrix (that is, rows * columns), the missing values will default to 0.0. Conversely, if there are too many elements, only the first (rows * columns) will be taken into account.

columns

The number of columns (n) that the newly created matrix will have. Must be an integer greater than 0.

rows

The number of rows (m) that the newly created matrix will have. Must be an integer greater than 0.

def echelon: (Matrix, Int)

Work in progress - not implemented fully. Does nothing in its current form except returning: the same matrix as the one upon which this method is called, if isInRowEchelonForm is true, and the number 1.

Work in progress - not implemented fully. Does nothing in its current form except returning: the same matrix as the one upon which this method is called, if isInRowEchelonForm is true, and the number 1.

To get the correct determinant of the output matrix, multiply the normally obtained result by the second element of the Vector returned by this function.

This is because each row swapping operation impacts the determinant of a matrix by changing its sign. Thus, the second value returned by this function keeps track of the number of such operations that were performed by the function whilst getting the original matrix to the row echelon form.
